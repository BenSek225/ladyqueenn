# Lady Queenn 👑

> **La maison du raffinement ivoirien**  
> *Beauty. Roots. Ritual.*

Lady Queenn est une **maison de luxe ivoirienne contemporaine** qui célèbre l'élégance africaine à travers trois univers complémentaires. Nous créons une expérience d'achat où tradition et modernité se rencontrent, où chaque produit raconte une histoire d'authenticité et de savoir-faire.

## 🌟 Notre Vision

**"Embrace Your Queenn Energy"**

Lady Queenn incarne le **raffinement accessible**, une élégance naturelle qui ne cherche pas à impressionner mais à inspirer. Nous croyons que le luxe véritable réside dans l'authenticité des matières, la qualité du geste artisanal, et la beauté intemporelle des rituels quotidiens.

### Notre ADN

- **🏛️ Héritage Contemporain** : Racines africaines, expression moderne
- **✨ Luxury Conscient** : Premium sans ostentation, élégant sans excès
- **🌿 Naturel & Artisanal** : Ingrédients purs, confections manuelles  
- **🤝 Inclusif & Chaleureux** : Accessible sans compromis sur la qualité
- **⏳ Intemporel** : Design qui traverse les modes et les saisons

## 🚀 Stack Technique

### Architecture Moderne & Performante

**Framework** : Next.js 16.3 (App Router) avec React 19  
**Language** : TypeScript 5.7 (typage strict)  
**Styling** : Tailwind CSS 4.3 + Design System custom  
**State Management** : Zustand 5.0 (panier persistant)  
**UI Components** : Shadcn/ui + Lucide Icons  
**Animations** : Lenis smooth scroll + reveal animations  
**Analytics** : Vercel Analytics  
**Deployment** : Vercel (Edge Functions)

### Design System

**Direction Artistique** : Luxury Editorial × Organic Minimal × Image-First

**Palette** :  
- Fond : Cream White (#F9F6F1)
- Texte : Deep Black (#1A1714)
- Accent : Champagne Gold (#C6A87C)
- Volets : Sage (Sweet-Hair), Plum (Fragrance), Terracotta (Crochet)

**Typographie** :  
- Display : Playfair Display (serif élégante)
- Body : Inter (sans-serif lisible)
- Mono : JetBrains Mono (prix, specs)

**Motion** : Smooth transitions, reveal au scroll, hover doux

## 🚀 Installation & Développement

### Prérequis

- Node.js 18+ 
- npm, yarn ou pnpm

### Installation

```bash
# Cloner le dépôt
git clone https://github.com/BenSek225/ladyqueenn.git
cd ladyqueenn

# Installer les dépendances
npm install
```

### Développement

```bash
# Mode développement
npm run dev

# Build production
npm run build
npm start

# Vérifier TypeScript
npx tsc --noEmit
```

Le site sera accessible sur [http://localhost:3000](http://localhost:3000)
